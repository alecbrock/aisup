## Decisions Made

- **Decision:** Keep `roles` out of `CONFIG_DEFAULTS`; compute it in `validateRoles`.
  **Rationale:** Backward compatibility requires synthesis from the operator's actual `workers.routing`, not from a static default that could drift from config.
  **Alternatives rejected:** Static default roles in `CONFIG_DEFAULTS`.

- **Decision:** Claude accounts with no usable telemetry are optimistically available with `headroom_pct: null` and basis `unknown`.
  **Rationale:** Unknown -> unavailable would make every never-seen account unavailable at cold start, collapsing the account-first failover guarantee.
  **Alternatives rejected:** Treat unknown telemetry as unavailable.

- **Decision:** `UsageLedger.estimateBudget(provider, nowMs, cfg)` takes the live budget config.
  **Rationale:** A lowered cap must take effect immediately; relying on a stored cap would be stale until the next consumption record.
  **Alternatives rejected:** Original plan shape `estimateBudget(provider, nowMs)` using only persisted cap.

- **Decision:** Codex budget charges `input_tokens + output_tokens`; cached input and reasoning output are excluded from the cap.
  **Rationale:** Matches the plan's budget basis and the real `codex exec --json` fixture fields.
  **Alternatives rejected:** Counting cached or reasoning tokens in the configured cap.
